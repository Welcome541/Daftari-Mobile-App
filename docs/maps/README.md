# خريطة شاشات دَفتَري 3.0

هذه **أربعة مخططات شجرية** — واحد لكل تبويب: الرئيسية، العملاء، التقارير،
الإعدادات — تشرح **كل ضغطة داخل التطبيق وما تظهر بعده**.

| الملف | الحجم | المحتوى |
|---|---|---|
| `home.png` | 3200 × 12262 | الرئيسية: بطاقتا اليوم، البحث، الفلترة، آخر العمليات، أزرار الدين والسداد، المعالج، المسجّل |
| `customers.png` | 3200 × 11051 | العملاء: البحث، فلترة العميل، ملف العميل، الفاتورة، المرتجع، التصدير، الأرشفة |
| `reports.png` | 3200 × 5507 | التقارير: الفترة، اختيار العميل، الرسم البياني، الطباعة، تصدير Excel |
| `settings.png` | 3200 × 8885 | الإعدادات: الحساب والعملة، المظهر، الأمان، البيانات، VOSK، العرض والمقاسات، التحديث، الإضافات |
| `cover.png` | 3200 × 1616 | صفحة الغلاف |
| `daftari-3.0-screen-maps.pdf` | 5 صفحات | الغلاف + الخريطة كاملة بمقاس الملصق (2000×‏H نقطة) |

كل ملف `*.svg` هو **المصدر** — عدّله ثم أعد الرسم.

## هذه الصور مرسومة آليًّا

لا رسم يدوي في أيّ منها. السلسلة:

```
web/src/js/*.js  ──►  map-ui.mjs  ──►  ui-map.json  ──►  render-maps.mjs  ──►  PNG + PDF
   الكود نفسه        متصفّح حقيقي        شجرة الضغطات        مخطّط SVG
```

### ١. `tools/map-ui.mjs` — المستخرِج

يشغّل التطبيق المبنيّ داخل **DOM حقيقي** (jsdom)، ثم:

1. يزرع بيانات تجريبية (`demoFixtures`) حتى لا تكون أي قائمة فارغة.
2. يجمع كل عنصر يتفاعل مع اللمس: `onclick`، `onpointerdown` (الضغط المطوّل)،
   `onchange`، `oninput`.
3. **يضغط كل عنصر فعلًا**، ويسجّل ما حدث:
   - ورقة منبثقة (`openSheet`)
   - شاشة أخرى (تغيّر مكدّس التنقّل)
   - تنبيه (`toastMsg`)
   - تأكيد (`confirm`)
   - تغيير في حالة الشاشة (فلتر، تحديد، …)
4. **يعيد ترتيب الشجرة** بلا تكرار: الشاشة التي تُفتح من ضغطة تُفحص هي أيضًا،
   حتى ثلاثة مستويات، ثم تتوقف عند أول تكرار.
5. يلتقط **مخطّطًا تخطيطيًا** لكل شاشة: البطاقات، شريط البحث، الإحصاءات،
   القوائم، الأزرار السفلية — ليرسمها المصيّر كشاشة مصغّرة.

الناتج: `web/scratch/ui-map.json`.

### ٢. `tools/render-maps.mjs` — المصيّر

يحوّل الشجرة إلى **SVG** ثم إلى **PNG** عبر `resvg`، ويجمعها في **PDF** عبر
`pdfkit`.

- **العربية**: خط Cairo (من `@expo-google-fonts/cairo`) مع تشكيل حروف
  صحيح واتجاه ثنائي (`bidi`) — تحقّقنا من ذلك بالعرض الفعلي.
- **الأيقونات**: مستمدة من `00-icons.js` نفسها، فترسم الخريطة أيقونات
  التطبيق الحقيقية، لا رسومات تقريبية.
- **كل صفحة في PDF صورة**: لاfonts ولا تشكيل — فالمخرَج مطابق تمامًا للـPNG.

## إعادة التوليد

```bash
cd web
npm install
npm run build          # يبني web/dist
npm run maps           # يستخرج الشجرة ثم يرسم الخريطة
```

المخرجات في `docs/maps/`.

## الفحص

`npm run check:icons` يتأكد أن كل `ic('اسم')` يشير إلى أيقونة موجودة فعلًا —
وهي الفحص الذي كشف خطأ `ic('print')` (كان الاسم الصحيح `printer`، فظهر
كلمة `undefined` داخل زرّ الطباعة في شاشة التقارير).
