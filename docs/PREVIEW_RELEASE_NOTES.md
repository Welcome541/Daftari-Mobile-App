# دفتري الجديد — تجربة 2 (2.24)

APK تجريبي قابل للتثبيت، موقّع بمفتاح debug وليس إصدار إنتاج.

## تغيير التثبيت

- هوية جديدة معزولة: `ai.arena.dafter.next.trial20261023`، واسم العرض «دفتري الجديد — تجربة 2».
- لا يستبدل التطبيق القديم أو نسخة 2.23 التجريبية؛ لا تحتاج حذف أي منهما.
- قد تتسبب نسخة مثبتة في مستخدم آخر/ملف العمل/التطبيقات المزدوجة أو بيانات تثبيت محتفظ بها في رسائل تعارض النسخ السابقة. لا ندّعي تشخيص الجهاز دون رمز خطأ Android.
- لا تحذف بيانات التطبيقات الأخرى. ثبّت ملف **2.24** الجديد، وليس نسخة 2.23 المخزنة سابقًا في التنزيلات.

## إصلاح بدء التشغيل والتحقق الفعلي

كشف اختبار Android أن فحص الروابط الرمزية كان يرفض اختلاف مسار مجلد Android الخاص (`/data/user/0` و`/data/data`) قبل إنشاء WebView. جرى توحيد جذر التخزين الموثوق فقط، مع بقاء رفض الروابط المزروعة داخل ملفات الاستيراد. أُضيف اختبار JVM لحفظ هذه الحماية.

اجتاز commit `796b751` جميع بوابات النشر في [التشغيل 39887138411](https://github.com/Welcome541/Daftari-Mobile-App/actions/runs/39887138411)، بما فيها الاختبار الفعلي على محاكي Android 10. اختبارات Node: 104/104؛ ونجحت مجموعات JVM وAndroid Lint.

## شرط النشر لهذه النسخة

النشر مشروط بنجاح:

- اختبارات Node وJVM وAndroid Lint وتوقيع APK.
- تثبيت 2.23 و2.24 جنبًا إلى جنب على محاكي Android 10 (API 29).
- حذف 2.24 وإعادة تثبيته.
- فتح WebView الحقيقي، إنشاء بيانات دفتر وفحص الرصيد، التحقق من نسخة JSON الاحتياطية وAES-GCM، إعادة إنشاء النشاط وإعادة فتحه والتحقق من بقاء البيانات.

هذا اختبار محاكي فعلي وليس إثباتًا لتوافق كل هاتف. لم يُختبر الصوت بالنماذج الحقيقية والبصمة والكاميرا وكل الشاشات على الأجهزة.

استخدم بيانات تجريبية أو نسخة احتياطية، واحتفظ بالتطبيق القديم. نماذج Vosk/Whisper غير مضمّنة. إذا استمرت رسالة التثبيت، أرسل لقطة كاملة لها ونوع الهاتف وإصدار Android؛ لا تحذف بياناتك لمحاولة تجاوزها.
