# دفتري الجديد — Daftari Next 2.23 Preview

**APK قابل للتثبيت للتجربة، موقّع بمفتاح Android debug؛ ليس إصدار إنتاج نهائيًا.**

- تطبيق مستقل: `ai.arena.dafter.next.preview`. لا يستبدل التطبيق القديم أو نسخة Next النهائية.
- اسم العرض: «دفتري الجديد — تجريبي».
- متطلبات التثبيت: Android 5.0 (API 21) فأعلى. لم تُختبر جميع الأجهزة فعليًا.
- حمّل `Daftari-Next-2.23-Preview.apk` واسمح بالتثبيت من المصدر الذي فتحته عند طلب Android.
- ابدأ ببيانات تجريبية، أو صدّر نسخة JSON من تطبيقك القديم واستوردها هنا. تحقق من الأرصدة ولا تحذف التطبيق القديم.
- نماذج Vosk/Whisper ليست مضمّنة؛ يلزم استيراد نموذج متوافق لاختبار التعرف المحلي. دعم الميكروفون والبصمة يعتمد على Android/WebView والجهاز.
- تم إصلاح مسارات الحفظ والتعافي والجسر والبصمة PRF، لكن OCR والبصمة الفعلية والنماذج ودورة الحياة تتطلب اختبار جهاز. دعم الإقلاع على API 21 لا يعني ضمان جميع خصائص WebCrypto/WASM على WebView قديم.
- هذه النسخة قابلة للتصحيح؛ لا تستخدمها النسخة الوحيدة لبياناتك المالية. توقيع debug مختلف عن توقيع الإنتاج، وقد يختلف بين أبنية CI؛ صدّر نسخة احتياطية قبل أي استبدال/إزالة لاحقًا.

## قائمة تجربة مقترحة

1. إنشاء حساب وعميل، دين ودفعة، وتعديل فاتورة وإرجاعها، والتحقق من الأرصدة.
2. الأرشفة والحذف والاسترجاع والتراجع، وتبديل الحسابات والعملات.
3. إغلاق التطبيق وإعادة فتحه، تصدير نسخة احتياطية واستعادتها، وتفعيل PIN وإلغاؤه.
4. رفض/قبول أذونات الميكروفون والكاميرا وجهات الاتصال، وإلغاء منتقي الملفات.
5. استيراد كل نموذج صوتي منفصلًا، ثم التسجيل والإلغاء والخروج للخلفية.
6. الوضع الأفقي وأحجام الخط والشاشة المختلفة والعمل دون إنترنت.

أرفق عند الإبلاغ عن مشكلة: نوع الجهاز، إصدار Android وWebView، خطوات التكرار ولقطة شاشة؛ لا ترفق كلمات المرور أو بيانات العملاء الحقيقية.
