# دفتري — Daftari-Mobile-App (2.22)

غلاف Android مستقل لواجهة دفتري ومحركات التعرف الصوتي المحلية. الواجهة متجاوبة للهواتف الصغيرة والأجهزة اللوحية والحواسيب، وتدعم الاتجاهين العمودي والأفقي. تعتمد الأيقونات داخل الواجهة على SVG بحجم مضبوط، وتستخدم أجهزة Android 8+ أيقونة تشغيل متكيفة؛ مع صور PNG عالية الدقة للأجهزة الأقدم وأيقونات PWA.

الأنماط والأيقونات مضمنة محليًا، وحُذفت خطوط Google الخارجية حتى لا تعتمد الواجهة على اتصال الشبكة أو يتغير حجم النص حسب تحميل الخط.

## التثبيت والتوافق

- تنزيل APK: [الإصدار 2.22](https://github.com/Welcome541/Daftari-Mobile-App/releases/download/v2.22-offline/Dafter2-Offline-2.22.apk).
- Android 5.0 (API 21) أو أحدث، مع WebView حديث. يتطلب Whisper دعم WebAssembly و`SharedArrayBuffer` في WebView وذاكرة مناسبة؛ يمكن استخدام Vosk عند عدم توافرهما.
- معرّف الحزمة: `ai.arena.dafter.enhanced`، رقم الإصدار 2.22 (versionCode 222). يختلف عن APK الأصلي `ai.arena.dafter`، لذا يمكن تثبيتهما جنبًا إلى جنب، ولكل منهما بيانات مستقلة.
- صفحة الإصدار وملاحظاته: [v2.22-offline](https://github.com/Welcome541/Daftari-Mobile-App/releases/tag/v2.22-offline).
- APK موقّع بمخططَي V1 وV2.
- لم يتوفر جهاز Android فعلي في بيئة البناء؛ تم التحقق من نجاح البناء، سلامة الأرشيف، التوقيع، واستجابة الواجهة بعروض من 320 إلى 1440 بكسل دون تجاوز أفقي.

## استيراد النماذج

1. انقل ملف النموذج إلى الهاتف وثبّت APK من تطبيق الملفات. اسمح بالتثبيت من هذا المصدر إذا طلب Android ذلك.
2. افتح التطبيق وانتقل إلى **الإعدادات**.
3. لاستخدام **Vosk**، اختر استيراد نموذج Vosk وحدد أرشيف النموذج العربي بصيغة `.zip`، مثل `vosk-model-small-ar-0.3.zip`.
4. لاستخدام **Whisper**، استورد ملف GGML مثل `ggml-tiny.bin` (وليس ZIP أو GGUF)، ثم فعّل Whisper. يُهيّأ المحرك عند أول تسجيل.
5. وافق على إذن الميكروفون عند التسجيل. لا يتطلب استيراد النموذج أو التعرف الصوتي اتصالًا بالإنترنت. يجب استيراد النموذج يدويًا؛ فهو غير مضمّن في APK.

## البناء من المصدر

المتطلبات: JDK 17+ وAndroid SDK Platform 35. نفّذ `./gradlew assembleDebug`. يتطلب `assembleRelease` مفتاح توقيع محليًا في `signing.local.properties`؛ لا ترفع ملف الإعداد أو المفتاح أو كلمات المرور إلى Git.

## إعادة الهيكلة الجارية

بدأ فصل النشاط والتخزين والأذونات والجسر وملفات الويب على فرع العمل الحالي. هذه تغييرات تطويرية **لم يُبنَ لها APK بعد**؛ معلومات الإصدار 2.22 أعلاه تخص الإصدار السابق، ولا تُعد تحققًا من هذه التغييرات.

راجع [سجل التنفيذ والخطوات المتبقية](docs/CORE_REFACTOR.md) لمعرفة الملفات الجديدة وعقد الجسر وتغييرات أمان الاستيراد وحدود الاختبارات.

- اختبارات الفصل وإقلاع الواجهة: `npm ci && npm test`.
- اختبارات أمان التخزين والاسترجاع (JDK 17+): `./tools/test-storage.sh`.
- فحص تجميع المصادر فقط: `ANDROID_JAR=/path/to/android.jar ./tools/check-android-sources.sh`؛ لا ينتج APK.
- [تفاصيل الدفعة الثانية ونتائج الاختبارات الفعلية](docs/STORAGE_PHASE_2.md).
- بناء Android (JDK وSDK مطلوبان): `./gradlew assembleDebug`.

### طبقة الصوت الجديدة

أُضيفت خدمة صوت موحدة وحالات تسجيل وإلغاء، وأُزيل استبدال دوال التسجيل من تكامل Whisper. لم تتغير قواعد بيانات النماذج. راجع [سجل الدفعة الثالثة](docs/SPEECH_PHASE_3.md) للاختبارات وحدود إلغاء Whisper؛ نتائج الاختبارات الوهمية لا تعني اعتماد التعرف الصوتي على جهاز حقيقي.

### الجسر وأحداث الواجهة

أُضيف RPC v2 لعمليات Android مع معرّفات ومهل وإلغاء، ورُحّلت أحداث شاشات الصوت والتسجيل وجزء من الإعدادات إلى جدول أوامر محدد. [سجل الدفعة الرابعة](docs/BRIDGE_PHASE_4.md) يوضح ضمانات الإلغاء وحدوده والتوافق ونتائج الاختبارات.

### تحديث الدفعة الخامسة

مخطط وترحيل غير متلف للدفتر، حفظ متسلسل بلا fallback واضح عند فشل التشفير، واستعادة تنتظر معاملة التخزين. اختبارات Node: **63/63**. التفاصيل والقيود: [LEDGER_PHASE_5.md](docs/LEDGER_PHASE_5.md). لم يكتمل بناء APK أو التحقق على الأجهزة بعد.

### تحديث الدفعة السادسة

واجهة تعافٍ وتصدير إنقاذ، واستعادة نسخة الأمان بعد التحقق، ومعاملات تنتظر الحفظ للعمليات المالية الأساسية والعملاء والاستيراد الجماعي. اختبارات Node الحالية: **83/83**. التفاصيل والعمل الباقي: [RECOVERY_PHASE_6.md](docs/RECOVERY_PHASE_6.md). محاولة `assembleDebug` توقفت لغياب Java في البيئة الحالية؛ لم يُنتج APK ولم تُنفذ اختبارات أجهزة.

### تحديث الدفعة السابعة

نُقلت إدارة الحسابات والعملات واللغة والصور والأرشفة والسلة إلى معاملات تنتظر التخزين، مع حماية التراجع ومراجع السلة والصور المتأخرة. الاختبارات الحالية **100/100**. التفاصيل والبنود غير المنجزة: [ADMIN_PHASE_7.md](docs/ADMIN_PHASE_7.md). لا APK أو اختبار أجهزة جديد في هذه الدفعة.
