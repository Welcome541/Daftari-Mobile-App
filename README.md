# دفتري — Daftari-Mobile-App (مصدر 2.23.3)

تطبيق Android يعمل دون اتصال لإدارة دفتر الديون والسداد، مع محركات تعرّف صوتي محلية اختيارية. الواجهة مبنية على WebView، وتدعم العربية والإنجليزية واتجاه RTL، ومقاسات الهواتف الصغيرة والأجهزة اللوحية. الأيقونات SVG محلية ومقاساتها محددة من مكوّناتها؛ لا تعتمد الواجهة على خطوط أو خدمات ويب خارجية.

> **حالة الإصدار:** يتضمن المصدر إصلاح 2.23.3 لتحميل Vosk؛ أنشئ APK من المصدر أو استخدم ملف البناء الناتج من المهمة الحالية. آخر إصدار منشور في GitHub قديم ولا يشمل هذا الإصلاح.

## التثبيت والتوافق

- [آخر APK منشور: 2.22](https://github.com/Welcome541/Daftari-Mobile-App/releases/download/v2.22-offline/Dafter2-Offline-2.22.apk) — لا يتضمن تغييرات 2.23.2.
- معرّف الحزمة: `ai.arena.dafter.enhanced`؛ مصدر 2.23.3 يستخدم `versionCode 226` و`versionName 2.23.3-vosk-worker-url`. يختلف معرّف الحزمة عن النسخة الأصلية `ai.arena.dafter`، لذلك يمكن تثبيتهما جنبًا إلى جنب ولكل منهما بيانات مستقلة.
- الحد الأدنى Android 5.0 (API 21). لا يدعم Android System WebView عزل Cross-Origin، ولذلك لا يتوفر `SharedArrayBuffer` اللازم لنسخة Whisper متعددة الخيوط داخل APK، حتى مع HTTPS وترويسات COOP/COEP. يعطّل التطبيق Whisper داخل WebView ويعرض السبب؛ استخدم Vosk أو محرك الهاتف لتسجيل الصوت. يمكن تشغيل Whisper على متصفح متوافق يدعم `crossOriginIsolated` و`SharedArrayBuffer`.
- لا يتضمن APK نماذج التعرف الكبيرة. يستوردها المستخدم إلى مساحة التطبيق الخاصة.
- لم يُختبر هذا الإصدار على جهاز Android فعلي؛ اختبر تسجيل Vosk/محرك الهاتف على WebView فعلي قبل إصدار نسخة إنتاجية.

## استيراد وتشغيل المحركات

### Vosk

1. افتح **الإعدادات ← المحركات والنماذج ← استيراد ملفات Vosk** واختر ZIP يحتوي `am/final.mdl`، مثل `vosk-model-small-ar-0.3.zip`. المحرك `vosk-browser.js` مضمّن؛ لا حاجة لاستيراده منفصلًا عادةً.
2. يحوّل التطبيق الأرشيف إلى نسخة محلية واحدة في مساحة التطبيق الخاصة (`getFilesDir()/imports/model-ar/model.tar.gz`). إعادة الاستيراد تستبدل النسخة الحالية بدل إنشاء نسخ متكررة؛ مسح بيانات التطبيق أو إلغاء تثبيته يحذف النموذج.
3. بعد الاستيراد، لا يلزم استيراد النموذج مجددًا عند إغلاق التطبيق أو إعادة تشغيل الهاتف؛ يهيئه التطبيق تلقائيًا من مساحة التخزين المحلية. يستخدم المحرك عنوان HTTPS مطلقًا عند تمرير النموذج إلى Web Worker لتفادي فشل حل المسار النسبي. إن فشل التحميل تظهر رسالة الخطأ بدل انتظار انتهاء المهلة فقط.
4. نطاق السجل المقبول: في حساب العميل، عميل مسجل أو محدد مسبقًا، ومنتج، ومبلغ؛ وفي الحساب الشخصي يلزم المنتج والمبلغ. يمكن مطابقة خطأ إملائي صغير وفريد في اسم عميل، كما تدخل أوصاف المنتجات السابقة ضمن مفردات التطبيق. للمنتج الجديد وغير المعروف قل «منتج» أو «صنف» قبل اسمه. يرفض التطبيق الكلام الذي لا يطابق هذه الشروط ويعرض الحقول للمراجعة قبل الحفظ. تشمل التطبيع صيغًا شائعة للأعداد وبعض ألفاظ المنتجات في لهجات مصرية وخليجية ويمنية وشامية وعراقية ومغاربية؛ هذه معالجة للنص بعد تفريغ Vosk وليست تدريبًا صوتيًا أو ضمانًا لتغطية جميع اللهجات والنطقات.

### Whisper

1. من بطاقة **Whisper دون إنترنت (GGML)** في الإعدادات، اختر **استيراد ggml-tiny.bin**.
2. اختر ملف Whisper بصيغة GGML، مثل `ggml-tiny.bin`، بحجم 8–500 MB. لا تختر ZIP أو GGUF أو نموذج Vosk.
3. يفحص التطبيق الامتداد والحجم وترويسة GGML، ثم يحفظ النموذج في IndexedDB المحلي. تُحذف نسخة النقل المؤقتة بعد نجاح الحفظ؛ لا يُرسل الملف إلى خادم.
4. فعّل مفتاح Whisper. يُحمّل WebAssembly ويُهيّأ عند أول تسجيل. إذا لم يدعم WebView العزل المطلوب أو تعذر تحميل الملف، يعرض التطبيق السبب.
5. إزالة النموذج من البطاقة تحذف نسخة IndexedDB وأي نسخة نقل مؤقتة باقية.

### استيراد مشروع HTML أو ZIP

- من **الإعدادات ← المحركات والنماذج ← استيراد مشروع**، اختر ملف `.html`/`.htm` مستقلًا أو ZIP يحوي `index.html` أو `app.html` في الجذر. يقبل ZIP الذي يضع المشروع داخل مجلد علوي واحد.
- يستبدل استيراد HTML المنفرد المشروع السابق؛ يُستبدل مشروع ZIP بعد نجاح فكّه والتحقق منه. تُخدم ملفات المشروع من أصل HTTPS منفصل عن دفتر دفتري، ولا يُتاح لها جسر JavaScript الأصلي أو أذنا الكاميرا والميكروفون. استخدم مسارات نسبية للملفات المرفقة؛ قد لا تعمل موارد CDN الخارجية في وضع عدم الاتصال أو مع عزل الموارد.
- بعد الاستيراد يفتح المشروع مباشرة. زر الرجوع في Android يعيد إلى دفتري.

## جسر Android للواجهة

الجسر `window.Daftari` متاح لصفحة التطبيق، وليس لصفحات المشروع المستوردة. تشمل الواجهات التي تستخدمها الواجهة:

- `pickVosk()`, `pickWhisper()`, `pickProject()` — اختيار ملفات الاستيراد.
- `hasProject()`, `projectEntry()`, `runProject()`, `openApp()` — حالة المشروع وتشغيله والعودة للتطبيق.
- `clearWhisperImports()` — إزالة ملفات GGML المؤقتة المنقولة إلى IndexedDB.
- `importedSummary()` — يعيد JSON بهذه البنية: `{"lib":true,"model":false,"modelBytes":0,"whisperModels":0,"project":"","projectRunning":false}`. المفتاح `whisperModels` يعدّ ملفات `.bin` المؤقتة في مساحة النقل المحلية فقط؛ بعد نجاح نسخ النموذج إلى IndexedDB يُتوقع أن يعود إلى صفر. `importedList()` يعرض قائمة الملفات المنقولة وأحجامها.

## البناء والاختبار من المصدر

يمكن تشغيل اختبارات تطبيع الأرقام وحدود تحليل العبارة دون تثبيت حزم إضافية:

```bash
node scripts/test-voice-ar.js
```

هذه الاختبارات لا تشغّل نموذج Vosk ولا تغني عن اختبار WebView على جهاز Android. للبناء، المتطلبات JDK 17+ وAndroid SDK Platform 35. من جذر المستودع:

```bash
./gradlew assembleDebug
```

يُنتج البناء عادةً `app/build/outputs/apk/debug/app-debug.apk`. يجب تثبيت APK واختبار تدفقي Vosk وWhisper وتشغيل مشروع مستورد على WebView فعلي قبل النشر؛ فاختبار DOM أو تحليل صياغة Java لا يعوّضان ذلك. يتطلب `assembleRelease` إعداد توقيع محلي في `signing.local.properties`؛ لا ترفع الملف أو مفاتيح التوقيع أو كلمات المرور إلى Git.
